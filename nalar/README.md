# Nalar

Game Android pengasah pikiran, empat mode dalam satu aplikasi.

- **Mesin Aturan**: tebak aturan rahasia dari contoh angka (30 level, soal dibuat otomatis, jawaban pasti satu).
- **Detektif Kilat**: temukan pelaku lewat pernyataan yang jujur atau bohong (30 level, kasus dibuat otomatis, selalu satu jawaban).
- **Timbangan Ajaib**: cari koin palsu dengan jumlah timbang terbatas (9 level).
- **Bayangan Diri**: gerakanmu direkam dan diulang sebagai bayangan yang membantumu (6 level, semua terbukti bisa diselesaikan).

Ikon dibuat dari kode: `flutter test tool/make_icon_test.dart`.
Tes: `flutter test`.
